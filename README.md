# 🎵 Music Player Website

## About
This is a **simple music player website UI** created using **HTML and CSS**.  
It shows how a music player looks with album art, song details, controls, progress bar, and volume slider.

> This project focuses only on **design (UI)**.  
> No JavaScript is used, so the buttons are not functional.

## Features
- 🎶 Music player layout  
- 🖼 Album image display  
- 📝 Song title and artist name  
- ⏳ Progress bar (UI only)  
- ▶️ Play, Next, Previous buttons (UI only)  
- 🔊 Volume slider  
- 🎨 Clean and attractive design  

## Technologies Used
- HTML  
- CSS  

## How to Run
1. Download or clone the project  
2. Open `index.html` in any web browser  
3. The music player UI will appear on the screen
