# 🎵 Music Player UI

## Description
This is a **simple and visually appealing music player UI** built using **HTML and CSS**. It is designed as a front-end interface that mimics the look and feel of a real music player. Users can see album art, song information, a progress bar, playback controls, and volume control.

> **Note:** This version is only the UI. To make it functional (play/pause, seek, and volume adjustment), JavaScript is required.



## Features
- 🎨 Attractive **album art** with hover animation  
- 🎵 **Song title and artist** display  
- ⏱ **Progress bar** representing playback position  
- ▶️⏮⏭ **Play, Previous, and Next controls** (UI only)  
- 🔊 **Volume slider**  
- 🌈 Modern gradient background and responsive layout
